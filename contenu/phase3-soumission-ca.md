# Phase 3 — Soumission au C.A.
## Gestion documentaire 2.1 — OAQ

*Printemps 2026*

---

## Contexte

La Phase 4 définit comment les projets sont gérés dans Teams jusqu'à leur archivage. Mais elle ne répond pas à une question critique : quand un document de projet est prêt pour le conseil d'administration, comment le transférer sans créer deux versions vivantes du même fichier ?

Sans protocole clair, trois problèmes surviennent :
- Le document original est déplacé hors du canal de projet, perdant son contexte de travail
- Des copies multiples sont créées à différents endroits, causant confusion sur la version officielle
- Une fois le canal archivé, il devient impossible de retrouver le document source

Ce protocole résout ces trois problèmes en un seul mouvement simple.

---

## Principe fondamental : l'original reste dans le canal de projet

Le document Word original reste toujours dans le canal de projet. Ce qui se rend au C.A. est une copie PDF.

Ce principe garantit que :
- Le canal de projet conserve l'historique complet du travail (brouillons, commentaires, réunions, décisions intermédiaires)
- Le C.A. reçoit un document stable et non modifiable
- Même si le canal de projet est archivé des années plus tard, le PDF soumis au C.A. reste retrouvable par son nom et sa date

**Règle absolue :** on ne déplace jamais le document Word original hors du canal de projet.

---

## Pour information vs Pour adoption

Conceptuellement, un document peut être soumis au C.A. pour information ou pour adoption — un dépôt « pour information » n'a pas la même valeur institutionnelle qu'une résolution adoptée. **Cette distinction n'est pas une métadonnée séparée** : le PV de la réunion indique en texte ce qui a été adopté et avec quel numéro de résolution, et ce qui a été transmis pour information. C'est suffisant.

Tout document soumis au C.A. — qu'il soit pour information ou pour adoption — est déposé dans la bibliothèque centrale après la réunion s'il atteint le statut VFA ou VFP.

---

## Documents concernés

### La fiche synthèse (FS)

La fiche synthèse est le document central de la gouvernance. Elle résume pour les membres du conseil tout ce qu'ils doivent savoir pour prendre une décision éclairée : contexte, analyse, risques, recommandation.

- Elle est rédigée par le responsable du projet et vit dans le dossier Documents du canal de projet
- Elle est toujours pré-décisionnelle — elle présente l'analyse, pas la décision
- La décision et son contexte apparaissent dans le procès-verbal du C.A. (PV)
- Elle est nommée selon la nomenclature Phase 2 : `CA-FS-OTC-protheses-2025-11-15-VT.docx`

### Le document officiel soumis

Selon la nature du dossier, un deuxième document peut accompagner la fiche synthèse : une politique, un rapport, une analyse juridique, un projet de règlement. Il vit également dans le dossier Documents du canal de projet et est nommé selon la nomenclature Phase 2.

Seuls la fiche synthèse et le document officiel sont soumis au C.A. Les documents de travail, les brouillons, les comptes rendus de réunions de projet et les échanges dans le canal ne sont jamais soumis.

---

## Cycle de vie d'un document soumis au C.A.

| État | Code | Description | Emplacement |
|---|---|---|---|
| Version de travail | VT | Document en cours de rédaction. Devient la version soumise au C.A. sans changement de statut. | Canal de projet / Documents/ |
| Version finale adoptée | VFA | Adopté par résolution du C.A. | Canal de projet + Bibliothèque centrale (Phase 5) |
| Version finale publiée | VFP | Diffusé officiellement aux membres ou à l'externe | Canal de projet + Bibliothèque centrale (Phase 5) |

---

## Protocole de transfert vers le C.A.

### Déclencheur

Le responsable du projet juge que le document est prêt pour présentation au C.A. et qu'il a été révisé par toutes les parties concernées.

### Étapes

1. **Finaliser le document** dans le canal de projet. Il porte le suffixe VT.
   - Exemple : `CA-FS-OTC-protheses-2025-11-15-VT.docx`

2. **Exporter le document en PDF** en conservant le même nom de fichier.
   - Exemple : `CA-FS-OTC-protheses-2025-11-15-VT.pdf`

3. **Déposer le PDF** dans le dossier de réunion approprié de l'équipe `OAQ — Conseil d'administration`.

4. **Terminer.** Teams notifie automatiquement les membres de l'équipe — il n'y a personne à aviser séparément.

Le document Word original reste dans le canal de projet. Seul le PDF est transmis. On ne déplace jamais l'original.

---

### Après la réunion du C.A.

| Décision du C.A. | Action | Suffixe résultant | Bibliothèque centrale |
|---|---|---|---|
| Adopté (tel quel ou avec modifications) | Renommer dans le canal de projet ; produire la VFP si publié | VFA, puis VFP si publié | Oui, avec numéro de résolution |
| Renvoyé pour révision | Reprendre le travail dans le canal | VT (inchangé) | Non |
| Rejeté | Conserver comme archive dans le canal | VT (inchangé) | Non |

---

## Le rôle des procès-verbaux

Le procès-verbal (PV) du C.A. est le document officiel qui certifie les décisions. Il contient le numéro de résolution, la description de la décision prise et le résultat du vote.

La fiche synthèse explique le « pourquoi », le PV confirme le « quoi a été décidé ». Un outil d'IA qui interroge la bibliothèque centrale trouvera d'abord les PV pour savoir ce qui a été décidé, puis les fiches synthèses pour comprendre le contexte. Ces deux types de documents sont complémentaires.

```
CANAL DE PROJET             →   OAQ — CONSEIL D'ADMINISTRATION
  CA-FS-OTC-protheses-          2025-11-20/
  2025-11-15-VT.docx              CA-FS-OTC-protheses-
  (reste ici)                     2025-11-15-VT.pdf

Après adoption :
  CA-FS-OTC-protheses-      →   BIBLIOTHÈQUE CENTRALE
  2025-11-15-VFA.docx           CA-FS-OTC-protheses-
                                2025-11-15-VFA.pdf
```

L'original Word reste dans le canal du début à la fin. Le PDF circule.
